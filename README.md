# EnEscena - Sistema de Gestión de Alquiler

### Aplicación en Java para gestionar el inventario del equipo (proyectores, cámaras y sonido), cotizaciones, alquileres y devoluciones de la empresa EnEscena.

# Compilación y Ejecución

### Desde la terminal, navega hasta la carpeta del proyecto y ejecuta: 

#### javac Main.java
#### java Main

# Funcionalidades del Menú

## 1. Registrar nuevo equipo (validando los códigos)
## 2. Consultar inventario
## 3. Cotizar alquiler
## 4. Confirmar alquiler
## 5. Registrar devolución
## 6. Reporte general de ingresos
## 7. Salir
